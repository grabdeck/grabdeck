# Grabdeck 한국어 안내

유튜브 소재를 **찾고 · 정리하고 · 받는 것**을 한 앱에서 하는 리서치·다운로드 도구입니다.

- **리서치**: 키워드·채널로 조건(조회수·기간·쇼츠/롱폼)에 맞는 영상을 찾아 목록으로 모읍니다. 내 구독 채널 불러오기도 됩니다.
- **저장 채널**: 눈여겨볼 채널을 그룹으로 모아 두고 성장세를 봅니다.
- **보관함**: 찾은 영상을 목록으로 저장·관리합니다. 구글 시트처럼 셀을 편집·색칠하고, 열 필터·정렬로 다룹니다.
- **다운로드**: 채널·영상·쇼츠 주소를 한 번에 넣으면 조건에 맞는 영상만 골라 받고, 스프레드시트용 목록(TSV)과 자막(대본)까지 뽑습니다.
- **소재 포화도**: 소재(키워드)가 얼마나 많이 다뤄졌는지 썸네일 격자로 한눈에 봅니다.
- **댓글 인사이트**: 영상 댓글의 반응·키워드를 모아 봅니다.

다운로드 기능은 본인 소유 콘텐츠, 공공 저작물, 또는 권리자·플랫폼의 허락을 받은 콘텐츠에만 사용하세요. 저작권법과 플랫폼 약관을 지킬 책임은 이용자에게 있습니다.

## 다운로드

자기 컴퓨터에 맞는 것을 눌러 바로 받으세요.

- 👉 **[Windows 다운로드](https://github.com/grabdeck/grabdeck/releases/latest/download/Grabdeck-windows.zip)**
- 👉 **[macOS (Apple Silicon / M1 이상) 다운로드](https://github.com/grabdeck/grabdeck/releases/latest/download/Grabdeck-macos-arm64.zip)**

> Intel Mac은 지원하지 않습니다.
> 릴리스 페이지에 함께 보이는 `Source code (zip/tar.gz)`는 앱이 아니라 개발용 소스라 받지 않으셔도 됩니다.

## 설치

### Windows
1. 압축을 **전용 폴더**(예: `문서\Grabdeck`)에 풉니다. **바탕화면에 바로 풀지 마세요.**
2. `Grabdeck.exe`를 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요(개발자 서명을 하지 않은 앱이라 뜨는 창입니다).

> ⚠️ **`Grabdeck.exe`와 `_internal` 폴더는 항상 같은 위치에 두세요.**
> `_internal`에는 앱이 돌아가는 데 필요한 부품(ffmpeg·다운로드 엔진·화면 라이브러리 등)이 들어 있어, 파이썬이나 ffmpeg를 따로 설치하지 않아도 됩니다.
> exe만 옮기면 실행되지 않습니다. 바탕화면에서 실행하고 싶다면 exe를 **우클릭 → 바로 가기 만들기** 후 바로 가기만 옮기세요.

### macOS
1. 압축을 풀고 **Grabdeck**을 **응용 프로그램** 폴더로 옮깁니다(옮기지 않으면 자동 업데이트가 되지 않습니다).
2. 처음 한 번은 **마우스 오른쪽 클릭 → 열기 → 다시 열기**로 실행하세요. 그냥 더블클릭하면 "확인되지 않은 개발자" 경고로 열리지 않습니다.
3. 그래도 안 열리면 **시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 '그래도 열기'**를 누르세요. 한 번 열면 이후에는 더블클릭으로 열립니다.

## 처음 실행할 때

구매 메일로 받은 **참가 코드**(또는 이메일과 라이선스 키)를 한 번 입력합니다.

- 한 번 입력하면 저장되어 다음부터는 묻지 않습니다.
- 컴퓨터를 바꾸거나 새로 설치하면 다시 입력해야 합니다.
- 대소문자, 하이픈, 공백은 구분하지 않습니다.
- 실행할 때 인터넷 연결이 필요합니다.
- 리서치·저장 채널·소재 포화도에는 **YouTube API 키**가 필요합니다. 앱의 리서치 탭 → **⚙ API 키 → 발급 방법**에 그림 가이드가 있습니다(무료, 약 3~5분).

코드를 잃어버리셨거나 입력해도 통과되지 않으면 문의해 주세요.

## ViewMine에서 옮겨오시는 분

Grabdeck은 ViewMine의 새 이름입니다.

- Grabdeck을 처음 실행하면 ViewMine의 **설정·보관함·저장 채널·참가 코드가 자동으로 옮겨집니다.** 코드를 다시 넣을 필요가 없고, 남은 사용 기간도 그대로입니다.
- ViewMine도 계속 쓸 수 있지만, 새 기능과 수정은 Grabdeck에만 들어갑니다. 두 앱을 번갈아 쓰면 보관함이 따로 쌓이니, 옮기신 뒤에는 Grabdeck만 쓰시길 권합니다.
- **Intel Mac**은 Grabdeck을 지원하지 않아요. 지금 쓰시는 ViewMine을 그대로 쓰시면 됩니다.

## 언어

컴퓨터 언어를 따라 한국어 또는 영어로 열립니다. **⚙ 설정 → 언어**에서 바꾸고 앱을 다시 켜면 적용됩니다.

## 다운로드 속도와 자막

- 속도는 **보통(권장)**으로 두세요. 영상이 많을수록 **안전**이 좋습니다.
- **'빠르게' 속도에서는 자막(대본)을 받을 수 없습니다.** 빠르게 받으면 유튜브가 자막 요청을 대부분 막기 때문입니다. 자막 추출을 켜면 '빠르게'가 자동으로 막힙니다.

## 결과물로 만들어지는 파일

| 파일 | 설명 |
|---|---|
| `[업로더_조회수_날짜_제목_ID].mp4` | 받은 영상 |
| `youtube_list_<날짜>.tsv` | 목록(구글 스프레드시트에서 바로 열림) |
| `자막_<언어>_<날짜>.txt` | 언어별로 합친 자막(대본) |
| `downloaded_shorts.txt` / `downloaded_longform.txt` | 중복 방지 목록(아래) |

영상 파일 이름이 `[`로 시작해서 폴더 정렬에 따라 위나 아래 끝에 몰릴 수 있습니다.

### 중복 방지 목록

작업이 끝나면 저장 폴더 안에 이미 받은 영상의 ID가 기록됩니다(쇼츠·롱폼 파일이 따로). **다음에 같은 폴더로 실행하면 그 영상들은 건너뜁니다.**

- **지우지 마세요.** 지우면 다음 실행 때 전부 다시 받습니다.
- 일부러 다시 받고 싶으면 이 파일을 지우거나, 다른 폴더를 저장 위치로 지정하세요.
- 건너뛴 영상은 완료 창과 로그에 `이미 받은 영상이라 건너뜀`으로 표시되고 다운로드 개수에 포함되지 않습니다.

## 쿠키를 읽지 못한다고 나올 때

`브라우저 쿠키 사용`은 유튜브가 '로그인한 사용자'로 인식하게 해 차단을 덜 당하게 하는 기능입니다. **없어도 대부분 정상 동작합니다.**

**Windows + Chrome**: Chrome 127 버전부터는 쿠키를 읽을 수 없습니다(Chrome을 종료해도 안 됩니다). 두 가지 중 고르세요.

| 방법 | 내용 |
|---|---|
| 쿠키 없이 쓰기 | `쿠키 없이 계속`을 누르면 됩니다. 다음부터 묻지 않습니다 |
| Firefox 사용 | Firefox를 설치해 유튜브에 로그인해 두면 앱이 자동으로 찾아 씁니다 |

> Edge는 Chrome과 같은 구조라 대부분 똑같이 막힙니다. Firefox를 쓰세요.

나중에 다시 쿠키를 쓰려면 `브라우저 쿠키 사용` 체크박스를 켜기만 하면 됩니다.

## 삭제하는 방법

별도의 제거 프로그램이 없습니다.

### Windows
1. 압축을 풀어 둔 폴더(`Grabdeck.exe`와 `_internal`이 있는 폴더)를 통째로 지웁니다. 바로 가기도 함께 지우세요.
2. `Win` + `R` → `%LOCALAPPDATA%` 입력 → **`Grabdeck`** 폴더를 삭제합니다.

### macOS
1. 응용 프로그램 폴더의 **`Grabdeck.app`**을 휴지통으로 옮깁니다.
2. Finder에서 `⌘` + `⇧` + `G` → `~/Library/Application Support` 입력 → **`Grabdeck`** 폴더를 휴지통으로 옮깁니다.

> ⚠️ 설정 폴더를 지우면 참가 코드 기록도 함께 사라집니다. 받으신 코드는 잘 보관해 주세요.
> ViewMine에서 옮겨오셨다면 같은 위치에 `ViewMine` 폴더도 남아 있습니다. ViewMine을 더 쓰지 않으면 함께 지워도 됩니다.
> 다운로드한 영상·목록·자막은 여러분이 지정한 저장 폴더에 그대로 남습니다.

# Grabdeck

**한국어 안내 → [README.ko.md](README.ko.md)**

**Bulk video, thumbnail & subtitle downloader for creators.**

Paste channel or video URLs, set a minimum view count, and Grabdeck picks the matching videos and saves the files, a list (TSV) and caption transcripts. A Research tab with the YouTube Data API helps you find what to save.

- Website & subscription: **[booupgajang.com](https://booupgajang.com)**
- Support: **skykstarfam@gmail.com**

## Download

Get the latest version from **[Releases](https://github.com/grabdeck/grabdeck/releases/latest)**.

| Platform | File |
|---|---|
| Windows 10/11 | `Grabdeck-windows.zip` |
| macOS (Apple Silicon, M1 or later) | `Grabdeck-macos-arm64.zip` |

Intel Macs are not supported.

### Windows
1. Unzip the file into its own folder (not directly on the Desktop).
2. Run `Grabdeck.exe`. Keep `Grabdeck.exe` and the `_internal` folder together.

### macOS
1. Unzip, then move **Grabdeck** to the **Applications** folder.
2. Right-click → **Open** → **Open** the first time.
   If it is still blocked: System Settings → Privacy & Security → **Open Anyway**.

## First run

Enter the **email and license key (GRAB-…)** from your purchase email.
Don't have one yet? [Subscribe here](https://booupgajang.com/subscribe).

## Language

Grabdeck follows your computer's language (English or Korean). Change it any time in **⚙ Settings → Language** and restart the app.

## Your responsibility

Only download content you own or have permission to use. Grabdeck does not bypass DRM and does not host or redistribute any content.
